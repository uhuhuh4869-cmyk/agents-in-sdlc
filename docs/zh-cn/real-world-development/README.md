通过真实场景、完整应用和共享待办事项，体验 GitHub Copilot 在软件开发生命周期中的应用。你将通过迭代方式规划更改、编写代码、测试行为、审查拉取请求，并使用智能体管理工作。

## 场景

你是 Tailspin Toys 的新开发人员。这是一家虚构公司，为开发者主题的桌游提供众筹服务。团队待办事项已登记为 GitHub issue，可供你领取。内容既包括筛选和分页等功能开发，也包括无障碍和编码规范等质量改进。

## 选择工作环境

无论在哪里工作，都可以使用 GitHub Copilot。选择适合你开发方式的环境。每个 workshop 都有独立的设置步骤，并使用共享的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用智能体助手。体验 Plan 和 Autopilot 模式、指令、技能、自定义智能体、Playwright MCP、Agent Merge 以及实用的斜杠命令。

### [GitHub Copilot 应用][app]

并行运行多个智能体会话、切换会话模式、在 Canvas 中协作，并在桌面应用中管理 GitHub issue 和拉取请求。

### [GitHub Copilot 云端智能体][cloud]

将 GitHub issue 分配给异步智能体，引导其工作、监控进度，并审查它创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。无需离开编辑器，即可使用 Copilot Chat 智能体模式、MCP 服务器和自定义智能体。
